# 🌙 Fajer Alsamnah

## نظام ذكي لأوقات الصلاة والمنبه التلقائي باستخدام ESP32

![صورة المشروع](images/fajer-alsamnah.jpeg)

---

## 📌 نبذة عن المشروع

**Fajer Alsamnah** هو مشروع **IoT (Internet of Things)** يعتمد على لوحة **ESP32** وقطعة **Buzzer** صغيرة، ويهدف إلى إنشاء منبه ذكي لأوقات الصلاة، مع التركيز بشكل خاص على مساعدة المستخدم على الاستيقاظ لصلاة **الفجر (Fajr)**.

يعتمد المشروع على الاتصال بالإنترنت للحصول تلقائيًا على أوقات الصلوات اليومية من خلال **Prayer Times API** مجاني، بدلًا من إدخال وقت المنبه يدويًا كل يوم.

كما يوفر الجهاز **Lightweight Web Interface** يمكن الوصول إليها من الهاتف أو الكمبيوتر المتصل بنفس شبكة Wi-Fi.

من خلال صفحة الويب يستطيع المستخدم:

* مشاهدة أوقات الصلوات الخمس.
* تشغيل أو إيقاف المنبه لكل صلاة.
* تحديد مدة تشغيل المنبه.
* اختيار نوع نغمة المنبه.
* تحديث أوقات الصلاة يدويًا.
* مشاهدة الوقت الحالي للجهاز.
* التحكم في إعدادات المنبه بسهولة.

---

# 🎯 المشكلة التي يحلها المشروع

يعاني بعض الأشخاص من صعوبة الاستيقاظ لصلاة **الفجر (Fajr)**، خصوصًا مع تغير وقت الفجر من يوم إلى آخر ومن موسم إلى آخر.

في المنبهات التقليدية يجب على المستخدم تعديل وقت المنبه يدويًا.

على سبيل المثال:

```text
اليوم الأول       Fajr = 04:55
بعد عدة أسابيع    Fajr = 04:45
بعد شهر آخر       Fajr = 04:35
```

وهذا يعني أن المستخدم يحتاج إلى تغيير وقت المنبه باستمرار، وقد ينسى تعديل الوقت.

لذلك جاءت فكرة المشروع لتوفير نظام يقوم بهذه العملية **Automatically**.

# 💡 الحل المقترح

يقوم **Fajer Alsamnah** بالحصول على أوقات الصلاة من الإنترنت، ثم يقوم ESP32 بمقارنة الوقت الحالي مع أوقات الصلاة.

عند وصول الوقت إلى موعد الصلاة المحددة، يقوم النظام بتشغيل الـ **Buzzer** تلقائيًا.

بشكل مبسط:

```text
Internet
    ↓
Prayer Times API
    ↓
ESP32
    ↓
Prayer Schedule
    ↓
Alarm Controller
    ↓
Buzzer
```

وبذلك لا يحتاج المستخدم إلى تعديل وقت المنبه يوميًا.

## 📱 3. Lightweight Web Interface

يوفر الجهاز صفحة ويب بسيطة جدًا مصممة خصيصًا لتعمل على ESP32.

تم تجنب استخدام الصفحات الثقيلة والمكتبات الكبيرة حتى تكون الواجهة:

* سريعة.
* خفيفة.
* مناسبة لقدرات ESP32.
* مناسبة للهواتف.
* قليلة استهلاك البيانات.

يمكن فتح الصفحة من الهاتف عن طريق عنوان IP الخاص بالجهاز.

مثال:

```text

```

# 🔧 طريقة توصيل القطع

يتم توصيل الـ **Buzzer** مع ESP32 كالتالي:

| Buzzer | ESP32   |
| ------ | ------- |
| (+)    | GPIO 25 |
| (-)    | GND     |

## مخطط التوصيل

![مخطط توصيل ESP32 مع Buzzer](images/esp32-buzzer-wiring.png)

### التوصيل بشكل مبسط:

```text
        ESP32
     ┌───────────┐
     │           │
     │ GPIO 25 ──┼──────── (+) Buzzer
     │           │
     │ GND ──────┼──────── (-) Buzzer
     │           │
     └───────────┘
```

> ⚠️ ملاحظة: يجب التأكد من أن الـ Buzzer المستخدم مناسب للتشغيل من GPIO. إذا كان الـ Buzzer يحتاج تيارًا أعلى، يجب استخدام Driver Circuit مثل Transistor بدل توصيله مباشرة.

# ⏰ مزامنة الوقت Time Synchronization

يحتاج ESP32 إلى معرفة الوقت الحالي بدقة حتى يستطيع مقارنة الوقت مع أوقات الصلاة.

لذلك يستخدم المشروع **NTP (Network Time Protocol)** للحصول على الوقت من الإنترنت.

تم ضبط المنطقة الزمنية على:

```text
GMT +3
```

وهي المنطقة الزمنية المستخدمة في اليمن.

# 🔐 الجانب الأمني Security

المشروع مصمم أساسًا للعمل داخل الشبكة المحلية **Local Network**.

لذلك لا ينصح بفتح Web Server الخاص بالـ ESP32 مباشرة على الإنترنت.

يجب عدم نشر:

```text
Wi-Fi Password
```

داخل GitHub.

كما يجب عدم وضع أي:

```text
Private API Keys
```

داخل الكود إذا تم استخدام API يتطلب مفتاحًا في الإصدارات المستقبلية.

# 🌍 لماذا المشروع مناسب لليمن؟

تم تصميم المشروع مع مراعاة بعض الظروف المحلية.

## 1. ضعف الإنترنت

* تطبيق Android.
* تطبيق iOS.
* حساب.
* واجهة معقدة.

## 4. انخفاض التكلفة

المشروع يعتمد على:

```text
ESP32 + Buzzer
```

فقط كأساس للنظام.
